# 常见问题

## 启动

**双击没反应，或窗口一闪而过**

用命令行看错误：

```powershell
.\start.ps1
```

或：

```bash
./start.sh
```

常见原因是 Python 不在 PATH、版本不是 3.10–3.12、端口被占用。

**端口被占用**

```powershell
.\start.ps1 -Port 9200
```

```bash
PORT=9200 ./start.sh
```

**依赖装不上**

国内网络先换镜像：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

OCR 组件装不上可以跳过，聊天和资料库仍可用。

## 页面与账号

**打开是空白**

1. 确认 `http://127.0.0.1:9100/api/health` 返回 JSON。
2. 看 `data/logs/` 最近日志。
3. 浏览器强制刷新。

**忘记管理员密码**

停服务，备份 `data/`，用控制台的账号管理恢复，或直接改数据库。不要删库。

**注册关闭了**

管理员在控制台「用户」页或「登录方式」页开启自助注册。

**局域网设备打不开**

- 确认服务监听 `0.0.0.0`。
- 防火墙放行 9100。
- 用 NAS/电脑的局域网 IP，不是 `127.0.0.1`。

## 模型

**对话报上游错误**

模型服务没起、地址错、Key 错、模型名不一致。先在浏览器打开 `/v1/models` 验证。

**回答慢**

换更小的量化模型，开 GPU 层，降低上下文长度，或把模型放到另一台更强的机器上做节点。

**中文乱码**

统一用 UTF-8 保存文件，设置 `PYTHONUTF8=1`。

## 数据与备份

**数据在哪**

默认 `data/`：

- `workbench.db`：账号、会话、资料、任务
- `config.json`：运行配置
- `secret.key`：Key 加密主密钥
- `uploads/`、`exports/`、`logs/`

**怎么迁移到另一台机器**

停服务 → 打包整个 `data/` → 新机器解压到同目录 → 启动。路径变了也没关系，启动脚本会把不存在的模型路径改到包内。

**升级会不会丢数据**

不会。迁移按版本执行。升级前仍建议备份 `data/`。

## Docker / NAS

**容器一直重启**

看日志：

```bash
docker compose logs -f
```

检查 `data` 是否可写、端口是否冲突、架构是否匹配。

**镜像太大**

模型不在镜像里。镜像只有 Python 依赖和代码；模型用 volume 挂载。

**ARM NAS 能用吗**

可以，但要在本机 `docker build`，或用多架构镜像。

## API

**怎么给第三方客户端用**

控制台「API」页生成 Key，Base URL 填 `http://127.0.0.1:9100/v1`，模型名填可用模型。

**返回 401**

Key 不对、被停用，或请求没带 `Authorization: Bearer`。

**流式输出断了**

反代要关闭缓冲，读超时调到 300 秒以上。
