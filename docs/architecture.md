# 架构说明

> 本文是速览版。完整的现状测绘、开发流程、技术债清单与重构路线见 [architecture-handbook.md](architecture-handbook.md)。


## 总体

```text
浏览器（用户端 / 控制台）
        │  HTTP + SSE
        ▼
FastAPI 单服务 :9100
├── 认证、会话、CSRF、限流
├── 对话编排、上下文、工具调用
├── 知识库 / 资料库 / 长期记忆
├── 定时任务、文档生成、备份
├── 多机算力池、内容安全、配额
└── OpenAI 兼容 API
        │
        ├── SQLite（data/workbench.db）
        ├── 本机文件（上传、导出、日志）
        └── 模型服务（llama.cpp / Ollama / LM Studio / vLLM / 自定义）
```

一个进程、一个端口、一个数据库。没有消息队列，没有 Redis，没有必须的云依赖。

## 目录职责

| 目录 | 职责 |
| --- | --- |
| `backend/main.py` | 应用装配、静态托管、安全响应头、健康检查 |
| `backend/db.py` | 建表、版本化迁移、连接管理 |
| `backend/security.py` | 口令哈希、会话、CSRF、限流、权限 |
| `backend/routers/` | HTTP 路由，按领域拆分 |
| `backend/services/` | 业务逻辑：模型、检索、记忆、任务、文档、备份等 |
| `backend/console/` | 管理控制台静态页面 |
| `frontend/` | 用户端静态页面 |
| `tests/` | pytest 回归测试，使用临时数据目录 |

## 请求路径

### 对话

1. 浏览器打开 SSE 连接。
2. 服务端组装上下文：系统提示词、会话消息、选中的资料、记忆（若开启）。
3. 调用模型服务；流式块原样转发。
4. 结束后写入消息、调用日志、Token 用量。
5. 若触发内容安全规则，拦截并记录。

### 附件与资料

1. 上传落盘到 `data/uploads/`。
2. 解析器按类型提取文本（PDF / Office / 文本 / 图片 OCR）。
3. 切片后写入资料库。
4. 对话时按相关度取片段，拼进上下文，并记录引用。

### 定时任务

1. 调度器读取任务表和 cron 表达式。
2. 到点后在进程内起协程执行。
3. 结果写入会话、通知中心和运行记录。
4. 失败重试有上限，避免死循环。

### 文档生成

1. 助手输出 Markdown。
2. `docgen` 解析标题、段落、表格、列表。
3. 用 `python-docx` / `openpyxl` / `python-pptx` / `pymupdf` 渲染。
4. 文件写入 `data/exports/`，按保留策略过期清理。

## 数据

SQLite 单文件，开启 WAL 和外键。迁移按版本号顺序执行，记录在 `schema_migrations`。

主要表：

- 账号、会话、消息、附件
- 供应商、模型、路由、调用日志
- 资料库、知识库、记忆
- 定时任务、生成文件
- 用户组、配额、API Key
- 内容安全规则与命中记录
- 品牌配置、功能开关、提示词版本

`data/secret.key` 是供应商 Key 加密主密钥，必须与数据库一起备份。

## 为什么不用微服务

目标用户是个人、小团队、学校机房和 NAS 用户。单进程的好处：

- 安装只依赖 Python 或 Docker；
- 备份就是拷一个目录；
- 没有服务间鉴权、网络和版本兼容问题；
- 局域网里延迟低，SSE 稳定。

代价是单机吞吐有限。需要多机时，用“算力池”把模型服务分出去，工作台仍然是单入口。

## 扩展点

- 新模型平台：在 `backend/services/platforms.py` 加描述，在供应商预设里加一项。
- 新文档格式：在 `docgen.py` 的 `FORMATS` 和渲染函数里加。
- 新登录方式：在 `auth_providers.py` 和 `auth_oauth.py` 里加。
- 新内容安全规则：在 `moderation.py` 的规则表里加，或接模型复核。
- 新前端功能：后台「前台功能」页配置开关，用户端读取 `/api/front/features`。
