# 功能介绍

本地 AI 工作台不是单一聊天窗口。它把“对话—资料—任务—生成—管理”放在一个本地服务里，所有数据默认留在自己的机器上。

![功能中心](docs/screenshots/feature-center.png)

## 1. 对话

- 流式输出，支持中途停止、重新生成、编辑后重发。
- 多轮上下文按会话保存；每个账号的会话互相隔离。
- Markdown 渲染、代码高亮、表格、引用块。
- 附件解析：文本、PDF、Word、Excel、PPT、图片（OCR 可选）。
- 顶部显示当前模型；会话可切换模型和参数。
- 用户端自带“通用助手”和技能入口，技能由后台统一配置。

## 2. 工作台

工作台是“结构化任务模板”，不是固定表单。用户说一句需求，助手按模板补齐字段，再生成结果。

内置方向：

- **教师工作台**：备课、出练习、做课件大纲、分析学情。
- **金融投研工作台**：联网取数、公告摘要、研报提纲、数据表。
- **写作工作台**：提纲、初稿、改写、标题和摘要。
- **自定义工作台**：管理员在控制台定义字段、提示词和输出结构。

工作台支持保存草稿、分享链接、从历史继续。

## 3. 资料库与知识库

- 个人资料库：上传文档，本机解析、切片、检索。
- 总资料库：管理员维护的公共资料，按权限对用户开放。
- 对话时可按需勾选资料，回答会带引用来源。
- 支持格式：`.pdf`、`.docx`、`.xlsx`、`.pptx`、`.txt`、`.md`、`.csv`，以及常见图片。
- OCR 是可选依赖，装不上不影响其他功能。

## 4. 长期记忆

- 默认关闭，用户可在设置里自行开启。
- 每个账号独立保存，管理员可查看和清理。
- 记忆条目有上限，避免无限膨胀。
- 关闭后不再写入，也不参与后续对话。

## 5. 定时任务

- 按 cron 规则运行，支持一次性、每天、每周、自定义表达式。
- 任务可联网检索，结果写入会话和通知中心。
- 适合“每天看行业动态”“每周汇总资料”“到点提醒”。
- 可在用户端创建，也可在控制台统一管理。

## 6. 文档生成

回答可以直接导出：

| 格式 | 用途 |
| --- | --- |
| `.docx` | 报告、方案、教案、合同草稿 |
| `.xlsx` | 数据表、清单、统计结果 |
| `.pptx` | 汇报提纲、课程大纲 |
| `.pdf` | 定稿分发 |
| `.md` / `.txt` | 纯文本归档 |

生成文件有过期时间，可在控制台设置保留周期，到期自动清理。

## 7. 多机算力池

- 把多台机器上的 Ollama / LM Studio / vLLM / llama.cpp 登记为节点。
- 统一编成“池”，对外暴露一个模型名。
- 按节点健康状态和权重路由；单节点故障不影响整体。
- 工作台自身仍只占一个端口，客户端不需要知道后端有几台机器。

## 8. 组织、权限与配额

- 用户组：按组分配功能和额度。
- 角色：普通用户、管理员；管理控制台按角色显示入口。
- 配额：按天/月限制请求数、Token 或生成次数。
- API Key：为第三方客户端签发，可停用、可审计。
- 调用日志：记录模型、耗时、状态、Token 用量，便于排查成本。

## 9. 内容安全

- 本地关键词与规则先筛一遍。
- 可选调用一个模型做复核，命中后拦截并记录。
- 管理员可配置拦截提示、白名单和审计页面。
- 所有判断在本机完成，不把内容发给第三方审核服务。

## 10. 品牌与外观

- 品牌名、Logo、登录页文案、页脚、备案号。
- 控制台实时预览，保存后用户端立即生效。
- 适合给学校、团队或客户做一套自己的入口。

## 11. 运维能力

- 数据库版本化迁移，升级不丢数据。
- 一键备份/恢复：数据库、配置、上传文件打包。
- 健康检查 `/api/health`，返回服务名和版本。
- 日志中心：启动、请求、错误、模型调用。
- 内网穿透入口：可接自建隧道或第三方，默认关闭。
- 所有启停脚本都带 PID 和端口文件，避免重复启动。

## 12. OpenAI 兼容 API

```bash
curl http://127.0.0.1:9100/v1/chat/completions \
  -H "Authorization: Bearer <你的 API Key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen2.5:7b","messages":[{"role":"user","content":"你好"}]}'
```

`/v1/models` 返回当前可用模型。任何支持 OpenAI 协议的客户端都可以接进来。
